Projeto Integrador II - Sistema de Controle de Estoque Use Screen
Este é um sistema moderno, rápido e intuitivo desenvolvido para gerenciar o estoque de insumos e materiais da Use Screen. O projeto foi estruturado com foco em usabilidade (Design Thinking) e desenvolvido utilizando tecnologias modernas de desenvolvimento web para garantir excelente performance e uma experiência fluida para o usuário.

🚀 Sobre o Projeto
O objetivo do sistema é otimizar as operações do dia a dia da Use Screen, fornecendo controle em tempo real sobre a disponibilidade de insumos, facilitando o registro de entradas e saídas e oferecendo inteligência logística por meio de métricas cruciais de controle.

📱 Telas do Sistema
O aplicativo é dividido em 4 telas integradas que cobrem todo o fluxo operacional de estoque:

Tela 1 — Consulta de Estoque (Painel Principal):

Listagem completa de insumos cadastrados.
Filtros dinâmicos de busca (por nome, código ou status).
Alertas visuais claros para itens em nível crítico de estoque.
Tela 2 — Entrada de Insumos:

Registro rápido de recebimento de novos lotes de materiais.
Cadastro de fornecedor, quantidade e data de validade.
Atualização imediata do saldo total de estoque.
Tela 3 — Saída de Materiais:

Registro simplificado de consumo e baixas de estoque para produção.
Histórico detalhado de saídas para auditoria interna.
Prevenção de rupturas através de avisos de quantidade indisponível.
Tela 4 — Relatórios e Métricas Logísticas:

Visão analítica de dados fundamentais de armazenamento.
Gráficos e indicadores de Giro de Estoque, Cobertura e taxas de Ruptura.
Suporte visual na tomada de decisões de compra.
🛠️ Tecnologias Utilizadas
Este projeto foi construído utilizando as melhores ferramentas e práticas do ecossistema de desenvolvimento moderno:

Next.js (App Router): Framework React moderno focado em performance, excelente estrutura de pastas e roteamento de páginas ágil e automatizado.
Tailwind CSS: Framework utilitário de CSS que viabiliza o design escuro (Dark Mode), moderno, responsivo e altamente elegante do projeto.
JavaScript (ES6+): Código limpo, simples e de rápida manutenção, dispensando complexidades desnecessárias para acelerar as entregas.
Node.js (LTS): Ambiente de execução robusto para o gerenciamento das dependências do sistema.
💻 Como Rodar o Projeto Localmente
Siga o passo a passo abaixo no seu terminal para executar o projeto na sua máquina:

1. Clonar o Repositório
git clone https://github.com/SEU-USUARIO/meu-estoque.git
cd meu-estoque
2. Instalar as Dependências
npm install
3. Rodar o Servidor de Desenvolvimento
npm run dev
4. Acessar no Navegador
Abra o seu navegador e acesse: http://localhost:3000
